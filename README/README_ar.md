## ✨ الميزات الرئيسية

- **تقسيم الفيديو**: تقسيم مقاطع الفيديو الطويلة إلى مقاطع أصغر بناءً على مدة قابلة للتكوين.
- **تعديل السرعة**: تغيير سرعة تشغيل الفيديو (أسرع أو أبطأ).
- **إزالة ضوضاء الصوت**: اكتشاف وإزالة المقاطع الصوتية الصامتة أو المزعجة تلقائيًا باستخدام مرشحات highpass/lowpass وعتبات قابلة للتكوين.
- **فلاتر الصوت والفيديو**: تطبيق فلتر التدرج الرمادي أو إزالة المسار الصوتي بالكامل.
- **تسريع العتاد**: يستخدم الترميز المسرّع بالعتاد (libx264/h264) لإعادة ترميز الفيديو بشكل أسرع.
- **المعالجة المرحلية**: تطبيق المعالجة في خط أنابيب محدد (إزالة الضوضاء ← المعالجة الأساسية).
- **السمات الديناميكية**: يقوم التطبيق بالتبديل تلقائيًا بين الوضع الفاتح والداكن بناءً على إعدادات النظام.
- **حفظ الإعدادات**: يتم حفظ تفضيلات المستخدم محليًا واستعادتها عند إعادة تشغيل التطبيق.
- **أيقونة تطبيق ديناميكية**: تتغير أيقونة التطبيق بناءً على سمة النظام (فاتح/داكن).

> **ملاحظة**: ميزة إزالة الخلفية حاليًا **تجريبية** ومعطلة بشكل افتراضي. لا تنتج مخرجات في الإصدار الحالي.

## 🏗️ البنية

### خط أنابيب المعالجة

```
┌─────────────────┐     ┌─────────────────────┐     ┌──────────────────┐
│   إدخال الفيديو │ ──► │  معالج إزالة الضوضاء │ ──► │  المعالج الأساسي │ ──► الإخراج
└─────────────────┘     └─────────────────────┘     └──────────────────┘
                         (إذا تم تفعيله)
```

### المكونات الأساسية

| المكون | الملف | الوصف |
|--------|-------|-------|
| `VideoProcessor` | `video_processor.dart` | الفئة الأساسية المجردة مع منطق تنفيذ FFmpeg |
| `BasicVideoProcessor` | `basic_video_processor.dart` | يتعامل مع التقسيم والسرعة والفلاتر وإزالة الصوت |
| `NoiseRemovalProcessor` | `noise_removal_processor.dart` | تصفية الصوت مع highpass/lowpass + إزالة الصمت |
| `AppSettings` | `app_settings.dart` | إعدادات المستخدم المحفوظة عبر SharedPreferences |
| `AppConfig` | `app_config_loader.dart` | تحميل التكوين من `app_config.json` |

## ⚙️ دليل الإعداد

### المتطلبات الأساسية

- Flutter SDK (الإصدار ^3.9.2 أو أعلى)
- Android Studio / Xcode (لبناء التطبيقات المحمولة)

### التثبيت

1. **نسخ المستودع**

```bash
git clone https://github.com/crrrowz/Video_Splitter.git
```

2. **تثبيت التبعيات**

```bash
cd Video_Splitter
flutter pub get
```

3. **تشغيل التطبيق**

```bash
flutter run
```
