## ✨ الميزات الرئيسية

<ul style="list-style-position: outside; padding-right: 0; padding-left: 20px;"><li><strong>تقسيم الفيديو<strong>: تقسيم مقاطع الفيديو الطويلة إلى مقاطع أصغر بناءً على مدة محددة.</li><li><strong>تعديل السرعة<strong>: تغيير سرعة تشغيل الفيديو (أسرع أو أبطأ).</li><li><strong>إزالة ضوضاء الصوت<strong>: اكتشاف وإزالة المقاطع الصوتية الصامتة أو المزعجة تلقائيًا باستخدام عتبة قابلة للتكوين.</li><li><strong>فلاتر الصوت والفيديو<strong>: تطبيق فلاتر مثل التدرج الرمادي أو إزالة المسار الصوتي بالكامل.</li><li><strong>تسريع العتاد<strong>: يستخدم تسريع العتاد (مثل h264_mediacodec) لإعادة ترميز الفيديو بشكل أسرع.</li><li><strong>المعالجة المرحلية<strong>: تطبيق المعالجة في خط أنابيب محدد (مثل إزالة الضوضاء > إزالة الخلفية > المعالجة الأساسية).</li><li><strong>السمات الديناميكية<strong>: يقوم التطبيق بالتبديل تلقائيًا بين الوضع الفاتح والداكن بناءً على إعدادات النظام.</li></ul>

## ⚙️ طريقة التثبيت والتشغيل

<ul style="list-style-position: outside; padding-right: 0; padding-left: 20px;"><li>1. المتطلبات الأساسية: تأكد من تثبيت Flutter SDK على نظامك.</li></ul>

<ul style="list-style-position: outside; padding-right: 0; padding-left: 20px;"><li>2. نسخ المستودع: انسخ مستودع المشروع إلى جهازك المحلي (عند توفره).</li></ul>

```bash
git clone <repository_url>
```

<ul style="list-style-position: outside; padding-right: 0; padding-left: 20px;"><li>3. تثبيت التبعيات: انتقل إلى دليل المشروع وقم بتشغيل `flutter pub get` لتثبيت جميع التبعيات المطلوبة.</li></ul>

```bash
cd video_splitter
flutter pub get
```

<ul style="list-style-position: outside; padding-right: 0; padding-left: 20px;"><li>4. تشغيل التطبيق: قم بتوصيل جهاز أو بدء محاكٍ، ثم قم بتشغيل التطبيق.</li></ul>

```bash
flutter run
```
